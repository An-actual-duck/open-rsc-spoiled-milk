# A07.5L Elemental Sword Proc

A07.5L shares only the identical two-owner Elemental Sword sequencing: living
target, owner-supplied effect/chance rolls, ice projectile versus on-entity
presentation, owner-supplied debuff, owner-supplied damage roll, and an
auxiliary true-damage callback only for positive payload.

Formula ownership, random sources, damage settlement, primary ordering,
mitigation, contribution, hitsplats, lifesteal, packets, and death handling
remain with each event owner. The compiled fixture covers normal presentation,
debuff-before-damage ordering, no-effect rejection, and failed chance.
