# Leather and poisoned dagger visuals

Six full five-piece worn palettes are installed using dedicated appended animation
entries, retaining existing shapes: mediumhelm, hidegloves, hideboots,
chainmaillegs, chainmail. Other leather families sharing those shapes are unchanged.
The approved inventory icons are installed with explicit native visible bounds.
Colors: frog #238fff; naga #589d40; terror dog #d34538; bloodveld #e3b59a;
dark beast #55565a; ugthanki #efd04b. Dark beast retains readable shading.

One-based worn appearances 1099–1128 follow family order above, then slot order
coif, gloves, boots, chaps, cuirass. Item ranges respectively: 3357–3361,
3369–3373, 3375–3379, 3381–3385, 3387–3391, 3394–3398.

Poisoned Dagger of Terror (3354) uses one-based appearance 1098 and the approved
poison inventory icon. Only the three-pixel blade tip band is green in held frames;
the final sideways combat frame uses its rightmost tip. Bone hilt, alpha, source
geometry and hand offsets remain unchanged. Base dagger is unaffected.

No stats, requirements, bonuses, poison mechanics, hides, tanning, or recipes changed.
Private visual testing remains the final check of the combined character rendering.
