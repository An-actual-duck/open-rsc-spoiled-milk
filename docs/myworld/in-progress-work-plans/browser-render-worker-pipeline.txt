Architecture and ownership contract
- Private renderworker=on selects OffscreenCanvas Worker with the SAME existing
  createBrowserWebGL backend, modules and shaders. Java VM, game/scene prep,
  input, AWT and literal C/T rendering stay main. Absent/OFF uses main backend.
  ON requires private async WebGL coverage and overlaydelta OFF. No quality,
  camera, fog or draw-distance reductions; no product UI or feature toggle.
- Explicit native command schema validates primitive types/intrinsic typed-view
  shapes, offsets/caps before byte-copy allocation. Preserve raw float bits.
  Reject SharedArrayBuffer. Clone only genuinely owned buffers during callback;
  transfer only copies, never Java arrays; no borrowed inputs retained.
- Two unACKed64MiB packets plus one64MiB producer and a16MiB/1024-buffer returned
  exact-size pool =208MiB maximum owned transport payload capacity. This is NOT
  a process-wide memory ceiling: Java sources, envelopes/strings, backend-owned
  metadata, driver/GPU storage, GC and engine overhead are additional.
- Worker returns packet buffers only after backend execution. Pool recency is
  refreshed on acquire/release; cold startup geometry is evicted for recent C/T
  planes. Exact byte overwrite on reuse; all pool refs cleared on fatal/dispose.
- Backend lifetime audit: chunk batches/bounds, readiness metadata, sky ranges/
  values, lighting values/mask bounds, atlas metadata/quads retain OWN copies.
  Raw C/T/palette/geometry/mask inputs are consumed synchronously by GL APIs.
  Hardware tests detach/overwrite every returned input then draw without
  resending unchanged resources, independently checking this contract.
- Ordered IDs and main-layout epochs; entire envelope/shape/entrypoint preflight
  before backend prefix execution. Backend semantic failure poisons transport;
  no false ACK or silent fallback after irreversible canvas transfer. Fatal,
  loss, disposal and startup rejection clear staging/reject pending promises.
- WORLD present closes at final frameWork, so backend world-frame/stat receipts
  are coherent. LOGIN/opaque present and holdWorld close directly. Resource
  prefixes stay ordered and are never dropped to cancel an unfinished frame.
- initialize and planWorldSprites are true result barriers: actual texture
  capability and atlas missing-image decisions come from existing backend,
  not duplicated state. They constrain overlap; no per-TEXT/JNI replacement.
- ACK means original backend execution/submission completed, NOT GPU fence or
  physical scanout. FPS uses Worker gpu.javaWorldFrames, never producer Java
  reportState FPS or transport completedFrames (which includes held packets).
- Main DOM rect/DPR and monotone size epoch explicitly feed the SAME physical
  size formula/capability. Worker rejects zero/missing physical layout. Main
  worker-only early loading uses positive measured #display and actual present
  logical extent before AWT canvas exists, then measures actual GPU canvas.
  Once AWT exists, original target alignment applies. Cached zero rect retries;
  positive steady rect stays cached until resize/DPR/display invalidation.
- Initial loading/input gate releases only after a completed actual WORLD frame
  and ready phase, not a queued declaration, held/LOGIN image, or resource ACK.
  Input/fit/fullscreen remain main-owned. No fake960/scale1 physical fallback.
- Bounded closed stats object/history whitelist, sample shape/depth/string caps;
  no framebuffer/typed-plane/cache diagnostic clone. Actual push counters retain
  equal intervals/full-ring samples. Main measurement setting is ordered and
  its actual Worker policy acknowledged. No per-frame full-proof publication.
- Oracle-only completion-task RGBA capture precedes ACK/default drawingbuffer
  clearing; max one owned readback. Confirmed disposal observes backend ledger;
  ordinary disposal terminates promptly without claiming observed ledger0.
