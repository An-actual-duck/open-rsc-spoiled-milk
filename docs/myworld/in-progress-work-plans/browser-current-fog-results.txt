Scope
-----

No demonstrated FPS gain. ON had7.3% more natural actors, with camera jitter;
the raw FPS difference is not an isolated causal regression measurement.
Transition results are single passes, not general performance certification.
The explicit walking selections crossed the same source boundary but ended
one tile apart (OFF105,619; ON105,620). The original automatic OFF walking
assertion failed because its click stopped short; only its later explicit
Walk Here retry is accepted for the walking result.

Fewer source vertices were prepared (roughly6-16% in sampled locations), but
shadow maps still require distant casters. A camera diagnostic added five
held frames and eight preparation-demand events within the same source epoch.
The benchmark resets yaw each second, so this is not a measured180degree turn.

Decision and limits
-------------------
The modest indicative loading improvement does not justify enabling this
prototype with no demonstrated FPS benefit and new camera-demand holds.
CPU and independent frozen-lighting tests passed; the actual production-shader
GPU full-source/subset pixel oracle was not completed. No visual certification,
60FPS acceptance, public release or deployment is claimed.

Retain the implementation, immutable candidate and evidence for future research.
Next useful direction: reduce geometry packing/upload cost, including compact
shadow-only data, rather than introducing closer fog presets. This is a future
recommendation, not an implemented feature.
