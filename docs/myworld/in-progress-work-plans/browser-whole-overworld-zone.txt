First playable contract
-----------------------
1. Offline native Java baker uses the selected package and fresh full-source
   client JAR to construct all445L0/444L1/441L2 sectors, all manifest placements,
   real stacked upper roof heights and actual texture/material/settings data.
   It uses production builders and browser vertex/material packing. Exact source,
   definitions/models/textures/JAR/settings hashes bind the catalog. Upfront work
   is acceptable. All output goes below declared build/test categories.
2. Terrain resources own non-overlapping central48tile centroid domains. Pack
   the authentic full3x3 mesh FIRST, then select packed triangle rows so normals,
   diffuse smoothing and blend inputs retain the surrounding source context.
   Do not recompute cropped normals or double-paint positive stitching strips.
   Objects use current24tile static-cell ownership; animation cells remain live.
3. Every catalog resource is uploaded into a separate pinned WebGL arena before
   ready. GPU completion/capacity checkpoint is distinct from catalog parsing and
   command submission. Original shaders, shadow/roof masks, texture scope, fog and
   graphics quality stay intact. Main/Worker normal rendering remain unchanged.
4. The existing server-driven collision/picking/local dynamic working set remains
   authoritative. Unchanged local static objects resolve the same existing
   canonicalContentKey to pinned resources and skip regeneration/uploads. Mutated
   or animated cells mask the authored baked cell and use current live geometry.
   Explicit empty-cell keys remove destroyed last objects; no stale double draw.
   Authored distant state is a baseline until the server supplies local interest;
   the prototype cannot invent authoritative state outside that interest.
5. Global resources stay local-origin based. Per-frame global base translation
   makes them match the current camera without feeding global coordinates through
   legacy int transforms. Only normal visible/fog/frustum scope is drawn, while
   all source resources remain resident. Full source residency is not all-world
   draw submission, nor all classic CPU RSModel objects simultaneously active.
6. Source/settings/material mismatch fails closed with an actionable private
   error. A source epoch change with matching immutable content can reuse data;
   changed source bytes never quietly reuse stale geometry. Context loss/disposal
   invalidates readiness, with no false ACK or partial-catalog fallback. Upstairs/
   underground preserve local gameplay rendering with whole-L0 resources pinned;
   mode-active scope and source readiness must be reported separately.
