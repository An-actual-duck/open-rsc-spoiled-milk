Implementation and invariants
-----------------------------
clonetemplates=on requires private benchmark WebGL, wholezone+wholeram and static
scene admission. Java also checks actual browser presentation, signed requested
level0, a global native source snapshot at level0 and no live terrain patches.
Known animated scenery remains literal. The feature is not installed in generic
RSModel.clone or animation replacement. Ordinary/flag-OFF calls return the
literal source.clone outside locks, world snapshots and cache allocation.

The cache is per-client, synchronized, with lazy creation only in the ON path.
It verifies source identity, all current definition values and an exact owned
snapshot of every input consumed by the literal constructor. It stores a recipe
of the original clone result using capturePreparedState, with the complete scalar,
array and alias graph. Each hit instantiates distinct mutable model arrays and
runs the caller's original rotation/light/translation/picking/collision operations.
No scene membership, placement authority, GPU readiness or cached mesh is supplied.

Literal clone commits source transforms. A hit explicitly performs that same
commit before its exact post-commit source proof. A miss performs literal clone
and captures its actual result; if the proof/copy is refused it returns that
literal result. Dirty source transforms, materials, definition/settings/source
context changes and resets therefore rebuild rather than silently reuse stale
art. Cache copies do not retain caller-owned mutable arrays. Source cache models
remain borrowed inputs; arbitrary external concurrent reflection mutation is not
a new supported synchronization contract.

The prepared codec now supports an optional bounded pool and immutable preparsed
ModelLayout metadata. Template hits reuse private node metadata instead of copying
every descriptor node per clone. Small public scalar/root metadata arrays remain
owned per ModelArrays instance; output graph arrays preserve alias groups within
each model and remain disjoint between models. The default wire format and all93
RSModel fields are unchanged. The ordinary decoder retains its original meaning.

Budget and reset
----------------
At most256 recipes and16MiB conservatively charged template workspace, including
a reserved2MiB for temporary alias/layout capture. Primitive pool admission occurs
before copying; owned proof arrays are also bounded before copying. Prototype
face count>1024 or vertex count>8192 uses literal clone. The alias graph has at
most about2,100 nodes for admitted clone results; the reserved2MiB covers its
bounded descriptor/hash/parser scaffolding. Recipe bytes include pool primitive
payloads plus256B/entry, exact proof estimates, preparsed node metadata and1KiB
entry overhead. Insufficient budget/full capacity falls back to literal clone.

worstReservedBoundBytes intentionally records the admission reservation upper
bound (normally16MiB), not observed heap usage. retainedConservativeBytes and
peakChargedRetainedBytes are separate actual recipe charge sums. Live output
instances, canonical borrowed model cache, VM/GC metadata and total RAM are not
claimed by that ledger. Current fixture filled256 recipes at4,355,584 charged
bytes. Session/scope reset clears cache; signed/native/patch/settings changes
clear/refuse at the next factory request. The independent resident-input cache's
ordinary per-frame invalidation does not clear these unrelated source recipes.
