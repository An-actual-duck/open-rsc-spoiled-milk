Concrete source cost
Height probes already use primitive elevation access: loaded Sector.getTile returns
an existing Tile reference, while immutable chunks decode only1 legacy or2 wide
bytes. Creating a new Tile was not the remaining cost. World first called
Snapshot.covers (linear available-chunk search), then getGroundElevation (the same
search again), for each native halo vertex. A final-slot query in a25-slot regular
halo executes51 chunk coverage checks, including the existing tileOffset guard.

Change
NativeLayeredTerrainSnapshot adds getGroundElevationOrUnavailable. Its primitive
result is unsigned elevation or Integer.MIN_VALUE for unavailable source. World
uses it only after the unchanged loaded-sector-first path and unchanged checked
local/world/logical mapping. Visual halo relation and active fallback remain the
same; no current scene, terrain product, collision or selection authority changes.
Existing covers/getGroundElevation/createTile/findAvailableChunk methods remain
byte-for-byte unchanged and still serve all other callers.

The snapshot already owns a constructor-copied x-major/y-minor array, not a list.
The original constructor validates count, order and every chunk coordinate. New
eligibility additionally requires every immutable Chunk.size to equal declared
presentationChunkSize and constructor-only representable min/max chunk bounds.
A regular lookup uses int floorDiv, bounds checks, differences0..4 and direct array
indexing. No hot long delta arithmetic, new array/map, height cache or borrowed
workspace is used. The chunk's original availability/coordinate/encoding guard
still executes when reading its elevation bytes.

Public constructors historically accept mixed actual chunk sizes. They remain
accepted. Such irregular snapshots use the literal original first-covering-chunk
scan, preserving overlaps, voids, order, errors and unusual accepted shapes.
Constructor overflow rejection remains in the original checked coordinate loop;
there is no new rejection rule. Uniform pages retain their exact rectangle checks.

Control
spoiledmilk.browserHaloHeightLookup=true explicitly opts in; default false.
World.isBrowserHaloHeightLookupEnabled() reports that flag AND installed browser
presentation. Native/default paths retain the original World chain. Private
halolookup query/actual receipt wiring is separately owned by ai-1. No production
per-query counters or timers were added.
