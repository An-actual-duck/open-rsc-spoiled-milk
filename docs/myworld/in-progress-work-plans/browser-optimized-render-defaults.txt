Adopted browser startup render defaults (READY for manager integration)
===============================================

Only ordinary WebGL startup adopts the verified model batching and immutable
terrain query index. Rendering math, quality, view distance, UI and the desktop/
native/software paths are unchanged. Overlay delta/rectangles and all other
experiments remain ordinary OFF. This is not a 60 FPS claim.

One canonical JS resolver owns both property values. Ordinary WebGL resolves
both requested ON; benchmark omitted controls remain OFF with explicit ON/OFF
retained. Private URL switches are ignored outside benchmark mode. The final
property assembly replaces these two keys in legacy experiment property lists,
then appends exactly one value each, preserving other experimental properties.
Software contributes neither feature key.

Bootstrap admission precedes BrowserBridge.install, Scene construction and
Terrain initialization. Class.forName(name,false,loader) and method/native
signature checks discover supported classes without running their static
initializers. Ordinary missing/incompatible capability quietly resolves to
literal OFF; explicit benchmark ON remains a strict pre-start refusal.
Both features are validated before either property is written. No renderer or
hot-loop code changes. The normal policy receipt reports actual Scene/static
getters once Scene exists, under browserProof.optimizedRenderDefaults; bounded
existing periodic terrain diagnostics report current eligible snapshot metadata.
Unsupported old helpers remain quiet and do not manufacture enabled receipts.

A stage-only derived HTML route input permits the normal private test to use
its existing loopback server without a benchmark/fixture URL. It is restricted
to a loopback origin and known exact loopback endpoint/port pairs; invalid input
throws rather than falling back. Absent metadata keeps ordinary routing intact.
No product menu/query setting, proxy, server or account change is introduced.

explicitly non-daemon. Those facts do not establish why this session exited.
