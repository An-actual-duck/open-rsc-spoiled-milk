Browser resident static input reuse — focused implementation

Measured motivation: the sampled browser profile on frozen 4a396089 reported
~3.99ms/frame in the post-Scene resident-object append span. The input builder
recreated canonical static groups, TreeMaps, sorted identity arrays and FNV
content keys each frame although scenery usually did not change.

The optional browser-only path caches completed STATIC groups. Each frame it
still samples exact canonical primitive values (kind, world tile, object ID,
direction, both terrain elevations and live/presentation membership), comparing
them directly against an owned descriptor snapshot. This deliberately does not
trust incomplete game-object revision counters or mutable model identity.
Anchor object, region base, tile size and presentation revision must also match.

ANIMATED models are collected afresh and use the unchanged production builder
with current instance/model/transform versions. The sorted static and animated
cell streams are merged in original signed-key order; a colliding role key falls
back to the original full builder. Static canonical production already ignores
live model pose/color, and this cache preserves that policy exactly.

Native/software paths, explicit scenery diagnostics and oversized descriptor
sets use the unchanged uncached builder. Both descriptor arrays are bounded to
at most4MiB each; the animated index list and one set of immutable static groups
are also retained. Input caches release with the existing area/relog cache clear.
The retained anchor is invalidated by reference when the terrain frame changes.
No appearance bytes, picking rules, gameplay or public server state are changed.

Private control: -Dspoiledmilk.browserResidentInputCache=false before mudclient
class initialization. Default on only takes effect with an installed browser
presentation owner. This is not a claim of a measured FPS gain.

disabled checks against the literal unchanged production builder. Inputs include

real generated mesh coordinates, UV bits, normals, lighting, blend data, indices,
materials and variation masks are compared as well. Cases cover changing poses,
incomplete-revision setters, materialization/model availability, terrain edits,
presentation records, definitions, doors, negative planes, region/anchor changes,
reset, native fallback and descriptor budget. The independent uncached builder
remains available as the differential oracle. No browser/GPU result yet.
