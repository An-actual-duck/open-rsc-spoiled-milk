Geometry shadow renderer — WIP, not READY

Owner request (November 7, 2026): improve shadow fidelity while targeting 60 FPS
on the owner's 1920x1080 normal gameplay view. Maximum camera distance is a
separate stress case. High and Low quality modes are authorized. This deliberate
new architecture work supersedes the earlier pause on shadow tuning.

Current implementation: actual resident world VBO/material-index geometry casts
a directional depth texture. Terrain, walls, roofs and scenery receive filtered
sun visibility in the existing Remaster shader. Ambient, material shading,
independent glow and day/night presentation retain their existing ownership.
Classic is untouched. Off/Low/High are saved as shadow_quality in client settings.
Runtime override: spoiledmilk.shadowQuality / SPOILED_MILK_SHADOW_QUALITY.

High: 2048 near map, 32-tile half extent, 3x3 comparison-filter taps; 2048 far map,
96-tile half extent. Low: 1024 near map, 48-tile half extent, one hardware comparison
tap. The near map refreshes every rendered frame, including animated scenery.
Far contains static geometry only; changes in true static mesh/material alpha,
4 tiles of center movement, 0.08 degrees of sun movement or 150 rendered frames
invalidate it. Its texture and projection are updated together. Geometry uses
true logical-world X/Z anchoring across native origin rebases; RSC positions
are Y-down, so sun projection explicitly converts from lighting's Y-up vector.
Object-cell origins are identity metadata, not vertex translations: real object
meshes retain full presentation-local model vertices. Depth casters and receiving
objects therefore share the primary world presentation anchor; world meshes use
their own offset. An actual RSModel-builder regression caught the former double
cell offset and covers static/animated objects and signed-level origin rebases.
Receiver bias uses actual derivative geometry normals, preserving accepted
lighting normals. Sampling only attenuates direct sun, not ambient or glow.

Camera visibility/culling is not caster authority. The depth pass culls against
the light frustum and retains submitted physical roof casters when the camera
hides them. Global Hide Roofs is different: World currently omits those source
meshes, so absent roofs cannot cast. This work does not alter source readiness or
that loader policy. Interior geometry receives ambient light when a submitted
roof blocks direct sunlight.
Far shadows of animated scenery and sprite-shaped actors are not yet represented;
the static scenery milestone must not be described as complete character shadows.

GL 3 framebuffer/VAO support is optional. Absent support, shader initialization or
runtime pass failure logs an explicit fallback to the existing terrain mask.
Off executes no shadow pass. Bounded existing map textures are retained while
Off, then released on a quality resize, relog/session clear or context cleanup.

Opt-in GPU timestamps (spoiledmilk.shadowGpuTimings=true) use a nonblocking ring
and report each completed unique sample through OpenGLGpuTimer.SampleSink:
frame-render, shadow-near, shadow-far. Normal clients create no timer queries.
spoiledmilk.shadowBenchmarkLegacyMask=true is an explicit diagnostic old-mask
control for matched renderer A/B; it is not a player-facing mode.
Hidden diagnostic windows use spoiledmilk.openglHiddenDiagnostic=true with
openglHiddenWidth/Height. They are never shown/focused and install no input
callbacks. Offscreen throughput is not desktop presentation cadence acceptance.

Verification completed:
- Maintained client build, exact projection/Y-direction/rebase/finite-input and
  persistence checks, renderer menu/profile tests and full renderer guardrails.
- Actual RX 6700 XT hidden GPU pixel/state fixture: opaque silhouette, alpha
  cutout, flat/sloped/wall receivers, Low/High/actual-Off transitions, steady far
  caching, movement/geometry invalidation, idempotent cleanup and texture deletion.
  It asserts program, framebuffer, VAO/VBO/index, texture unit/binding, viewport,
  depth function/range/clear/write masks, color masks, culling and polygon offset
  restoration. Nested timestamp samples are completed and emitted uniquely.
- An actual GL 2.1 context reports unsupported optional GL 3 capability without
  creating the geometry pass; the previous ground-mask fallback remains available.
- Native benchmark exposed a pre-existing same-position teleport scenery reset:
  clearing local delivery sets retained a matching static scan key, suppressing
  the needed resend. Separate commit 7cba3d710 invalidates only that owned key at
  Player.resetLocalObjectState. Real reset/cache methods failed before and pass
  afterward (steady/version/region/level checks); native private proof retains
  all 935 scenery objects / 29 wall objects through the same-coordinate rebase.
- Client window diagnostics export cached visible/iconified attributes only when
  diagnostics are enabled. Observers never call GLFW off the context thread.
  Raw completed openGLFrameInterval samples are exported for cadence analysis.
- Last-completed shadow statistics are copied through a diagnostic-only lock;
  the GL writer uses tryLock and never waits for an observer. The observer alone
  allocates its requested snapshot, avoiding per-frame diagnostic allocation.

Repeatable optional GPU proof (hardware GL display required):
  ./scripts/build-client.sh
  DISPLAY=:0 tests/myworld/test-geometry-shadow-gpu.sh
  DISPLAY=:0 tests/myworld/test-geometry-shadow-gpu.sh --unsupported
The runner compiles the fixture, acquires the common renderer GPU lock and writes
pixel/state logs and PNGs under the declared tests/geometry-shadow-renderer run
category. It creates an unfocused hidden window and never installs input/grabs.
The unsupported variant requests Mesa GL2.1 and verifies capability detection;
it is not a complete full-client fallback-route proof.

Controlled real-frame caster isolation, diagnostic sessions only:
  -Dspoiledmilk.shadowDiagnosticExclude=TERRAIN
(or comma-separated WALL,ROOF,GAME_OBJECT,WALL_OBJECT). This filters depth caster
submission only, preserving color geometry and authority/readiness. It is not a
player option and is excluded from final performance/quality comparisons.

Superseded preliminary native evidence (candidate1; not acceptance):
Seers normal zoom 75, physical 1920x1080 / logical 960x540, fixed sun 135/45/day,
ordinary RSA login/native scene ACK, RX 6700 XT. Controlled busy scene has 17
players (viewer plus 16), 40 NPCs (32 plus 8 test bears), 57 submitted actor groups,
163 sprite layers. Eight emitters were requested, but later observation found
zero actual projectile actors in this preliminary run. No damage was simulated.
This artifact also had the object-cell shadow-offset defect described above, so
these timings must not stand in for corrected full-workload acceptance. A 60-second
High run measured CPU render p95/p99 3.822/4.243 ms and GPU render 6.638/7.155 ms;
no measured render sample exceeded 16.667 ms. This is hidden offscreen throughput,
not proof of compositor delivery, owner visual approval or all locations.
Near GPU p95/p99 .443/.742 ms; 23 far rebuilds with maximum 1.031 ms. Submission
coalescing is deferred because this measured workload leaves budget headroom.
