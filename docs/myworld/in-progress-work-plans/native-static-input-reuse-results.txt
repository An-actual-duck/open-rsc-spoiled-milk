Standalone static scenery input reuse — November 13, 2026
========================================================

Status: native implementation, repeated comparison and final runtime checks
complete; ready for manager integration and owner private playtest. No public
release or server activation is requested.

Decision and scope
------------------
Enable exact static resident INPUT-group reuse on the native hardware renderer.
This reuses the maintained browser algorithm with an independent native control,
not browser presentation or whole-world flags. The only production change is in
mudclient: native hardware may use the existing cache, while software rendering,
debug/oversized inputs, unavailable backends and explicit opt-out use the literal
builder. Browser policy retains precedence and its original independent opt-out.
Use -Dspoiledmilk.nativeResidentInputCache=false for the native diagnostic fallback.

Fresh descriptors still sample canonical kind, world position, object ID,
direction, terrain elevations and membership. Anchor, base, tile size and
presentation revision must match. Animated groups rebuild. Existing ordering,
collision fallback, maximum descriptor bound and region/relog clearing remain.
There is no new map authority, all-world cache, shader, texture or asset change.

The small total CPU-utilization change is not a broad CPU percentage promise.

capped near60FPS. This is reduced repeated work/allocation, not an FPS uplift.
Allocation and CPU use sums of telemetry deltas over complete runtime windows
fully inside the timed phase, excluding overlapping leading windows. Group time
uses window totals/counts. Earlier point samples at phase stop showed larger
rates; those are not the aggregate result used here.
