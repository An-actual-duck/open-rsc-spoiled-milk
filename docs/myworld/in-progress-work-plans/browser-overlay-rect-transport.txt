Observe-only contract
---------------------
Private benchmark WebGL URL: overlaydelta=on&overlayrect=observe. off is the
default; ordinary/software URLs inject no override. on is rejected until the
rectangle backend actually exists. Java browserOverlayRectMode=observe creates
one WorldOverlayTileTracker under the EXISTING WorldOverlayDeltaTransport.

All opaque/opaqueSpan/multiply writer hooks mark 32x16 tiles. Mark cache accepts
only an exact single-row horizontal interval; multirow linear tile bounds
contain other columns and cannot be used as an exact shortcut. Spans process
partial first/last rows and full intervening tile-row groups. Bounds are checked
before the fast cache. Metadata grid <=16,384 cells, no plane scans/packing.

The existing transport remains the sole transaction/history owner. Plan owns a
frozen actual-current tile snapshot. ACK advances acknowledgedTiles ONLY after
successful presentation; skipped/held source frames do not advance. First FULL
ACK retains actual current marks, never the uploaded full viewport. Invalidation,
owner/dimension changes and fallback reset the same existing history.

Uploads remain literal existing ROW/FULL operations. Current work[0..5] and
bands are unchanged. Observe adds work[6..14]: scheme1, currentTileCount,
currentArea, unionTileCount, unionArea, markerMisses, spanGroups, columns, rows.
work[15..] is owned 16-bit-word union occupancy (row-major tile IDs). This is
small bounded metadata, not borrowed planes; no additional per-frame JNI call.
Current+last ACK union is reported even when row transport falls back to FULL.

Pure native metadata validation checks observation opt-in, exact grid and
word count, bounded unsigned words, zero padding bits, and recomputes the union
tile count/edge-clipped area BEFORE any graphics call. No RGB/T pixels are read.
Existing retained token validation, draw/ACK, shader and upload bytes stay the
same. stats.overlayDeltaLast.transport reports row/full, rectangleMode reports
observe/off, and tileObservation reports real writer footprint plus its bitmap.
