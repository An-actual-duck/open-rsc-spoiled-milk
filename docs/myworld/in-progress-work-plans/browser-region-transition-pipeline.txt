The benchmark-only property spoiledmilk.browserRegionBuild enables:
* A construction-local RSModel.addModels XYZ index, earliest-index semantics,
  at most 262144 int slots (1MiB). Coordinates stay in authoritative model arrays.
  Inputs above 131072 predicted vertices, or unexpectedly growing beyond half
  occupancy, use the original scan. No persistent mutable-model cache exists.
  The index is discarded in finally; insertVertex outside this scope is literal.
* Two-int FNV-1a state in both object/world GPU signature loops. Array/field
  order and canonical Float.floatToIntBits remain identical; long is joined only
  at finish. Literal long hash loops remain the OFF branch.

  than 1048576 elements (4MiB), then converts to the original boxed representation
  for oversized accepted inputs. Final arrays are exact-sized owned copies;
  enum/effect order and all geometry/material/lighting data remain unchanged.
  This bounds additional primitive scratch, not total process/output memory.
