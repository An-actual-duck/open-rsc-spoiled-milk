Scope
-----
The maintained Java game now has an optional synchronous browser presentation
sink at ScaledWindow.setGameImage. Desktop presentation remains the default.
The sink borrows immutable Renderer3DFrame/Renderer2DFrame snapshots; the registry
releases pooled 3D ownership in finally on normal, null-image and failure paths.
WebGL2 receives primitive arrays and uploads/copies them before native calls
return. This is local Java game execution and browser GPU rendering, with the
normal private WebSocket server protocol and native world authority intact.
No desktop video stream, owner account, public server or production DB is used.

Renderer data
-------------
Resident geometry uses the production vertex/material/normal packer, camera
matrix arithmetic and GLSL resident shader strings. A small syntax adapter
converts GLSL120 to GLSL300es. Chunk storage signatures and presentation rebase
offsets identify resident GPU buffers. The implementation preserves original
texture pixels and game sprite artwork. RendererFrameLighting scopes the actual
immutable frame so signed negative levels retain the current neutral-light rule.

World sprites use the existing owned multipart snapshots, production composite
texture builder, exact native atlas texel centers and top/bottom depth estimator.
Camera-space quads receive ordinary GPU depth testing. Explicit per-entity
GPU_OWNED/FORCE_SOFTWARE policy keeps captured mirrored/skewed actors off the
software overlay, preserves native DEFAULT and rejects uncaptured GPU frames.
Completed actor-failure/coverage metadata survives command consumption until the
next actual begin-frame; native command/counter resets remain unchanged.

Ordinary UI pixels still come from the real software writers. Optional per-owner
transmittance reconstructs RGB + T * GPUworld using premultiplied blending.
Legitimate black UI remains opaque. Native integer-rounding differences up to
one channel step were observed in119 focused raster variants; this is not a
claim of universal bitwise image identity. Exact retained FULL/BASE GPU images
handle native packed-integer death/sleep fades without CPU world readback.
RGBA drawingbuffer alpha is explicitly normalized after world/before UI; every
final pixel stays opaque. The marker-only earlier path remains a comparison.

Resource ownership
------------------
Scene/chunk/viewport/texture and sprite-atlas dimensions are bounded. Geometry
and world textures have a256MiB budget; separately bounded resources include
16MiB sprite atlas, up to160MiB shadows,8MiB masks and2MiB Sky peak. Optional
C/T UI plus retained FULL/BASE textures enforce a combined32MiB peak by freeing
retained storage before viewport changes; actual960x540 usage is8,294,400bytes.
These texture/buffer ledgers exclude driver/program overhead. The optional exact
Java sprite cache is separately bounded16MiB and is a measured control.
Active chunks are protected; LRU reserves32MiB for textures and evicts inactive
buffers before uploads exceed the224MiB chunk budget. New buffer allocations
commit after GL checks; partial in-place failures explicitly require restart.
No borrowed frame arrays survive the synchronous native upload. Context loss
and backend errors are surfaced with actual frame age; Stop/restart is required.
