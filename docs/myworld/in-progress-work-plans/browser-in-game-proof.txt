Private browser in-game proof
=============================

Current state: READY for manager review. Actual visible world, authoritative
walking and scene transitions passed in a fresh 300-second final capture. This
is not a public browser release or deployment.

Scope and source
----------------
Baseline acb16e5c8bcd982d873addc5a49ffc89ddf0c863. Shared source change is a
semantics-preserving fill/bounded-override normalization for material families
and model kinds. The prior combined
nullable-array loop fails inside CheerpJ during actual halo cropping. Real
initial 43,788-triangle mesh succeeds, then the first 4,608-triangle presentation
cell enters with families=null and kinds.length=4608 and fails NPE. Ordinary
JVM does not reproduce it. Explicit nested branches alone did not resolve it;
separate kind fallback and supplied-family override passes do. The expanded
public-constructor probe then exposed the same nullable-array failure in
normalizeKinds after main-thread halo-size calls followed by worker calls with
null kinds. Its equivalent fill/nonnull-copy implementation resolves that
probe as well.

This does not establish a specific vendor/compiler root cause. It is a focused
source compatibility change with the same fallback mapping and copy semantics.
No runtime engine files or large maintained classes were replaced or shadowed.

Native terrain/atomic scene authority, readiness, collision and stage
acknowledgements remain required. No halo build is skipped. Current terrain,
objects, NPCs, sprites and content are used. Desktop GPU defaults are unchanged;
the browser bootstrap alone selects AWT software/direct framebuffer.

The unrelated keyboard/lifecycle WIP is explicitly deferred on ai1 and has not
been imported. No Oracle/public server, owner account or hosted DB was accessed.

Known limitations
-----------------

been ported. No production networking/security/distribution acceptance, no
full content/combat audit or keyboard-lifecycle claim. Tests use isolated
headless Chrome/CDP, never owner browser profiles or physical desktop input.

workspace-layout check reports inherited unclassified output entries and
assets/sprites in this reused worktree. New outputs use declared tests
categories only. No old data was deleted or reorganized.
