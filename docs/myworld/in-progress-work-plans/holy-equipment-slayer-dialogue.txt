Holy Power equipment display and Slayer dialogue ordering

Scope
- Equipment.getEquipmentHolyPower() exposes only the strongest equipped holy
  staff bonus. ActionSender uses it for the existing equipment-stat field.
- Equipment.getHolyPower() remains current Worship plus that equipment bonus;
  ClericSupportCasting and ClericHostileRuntime keep using the combined total.
- Successful Slayer assignments now render personality remarks, all task
  warnings in definition order, then the assignment and existing supply lines.
  This covers all six contacts and both Talk-to and Task routes without adding
  flavor to routes that previously omitted it.
- Active task reminders retain their warnings and progress. Failed assignments
  do not promise a task or supplies. Selection and supply transactions remain
  in the existing services; the contact no longer needs a separate preview.
- Generic and Bran/Doran Wilderness advice describes an optional hunting
  location instead of requiring the Wilderness.
