Source audit
-------------
Snapshot construction still accepts every previously accepted roster. Its
existing cloned x-major/y-minor9/25-slot array supplies a direct slot only if
EVERY chunk's own size equals the presentation size24/48, including void slots.
Those uniform chunks are disjoint, so floorDiv(worldX/Y,presentationSize) and
the stored minimum chunk coordinates identify exactly the old available chunk.
For any int world coordinate,24/48 divisors keep quotients and differences
well inside int bounds. Bounds checks precede dx*dimension+dy array indexing.
Explicit void returns null. Mixed sizes retain the original first-available
linear scan verbatim, preserving accepted overlap/precedence and void behavior.

Chunk construction caches inclusive int bounds only AFTER the original long
safe-coordinate checks. minimum=chunkCoordinate*size is then representable;
maximum=minimum+(size-1) is representable even when the old exclusive upper
bound equals Integer.MAX_VALUE+1. The OFF branch keeps the literal old long
comparison. No new constructor validity rule was introduced.

World/level identity checks in covers remain before lookup. Each snapshot owns
its final index metadata and cloned roster; no global map/cache or stale
cross-world index is introduced. Uniform protocol3 retains its original page
path. Tile source bytes remain copied; returned Tiles remain independent.
Merge and inner-window extraction construct fresh snapshots and derive their
own eligibility. There is no per-query allocation, new long arithmetic, boxed
Long hash lookup or hot-query diagnostic counter. Packet decoder, resident
cache, loader and Tile source are unchanged by this candidate.

Metadata and limits
--------------------
Read-only Bootstrap review confirms periodic metadata extends the existing
three region counters to eight numbers, retaining prefix order. Cached
reflection reads the current World's snapshot and reports present/eligible/
static-enabled/dimension/protocol; it does not instrument queries or retain a
queried tile. Null world or unavailable older API falls back to old metadata.
Eligibility and global static enablement are separate facts: an enabled flag
does not imply that a current uniform or mixed-size snapshot uses the index.
Agent1 owns execution of the dedicated Bootstrap/frontend metadata fixture;
this independent Java oracle proves the public snapshot diagnostics only.
