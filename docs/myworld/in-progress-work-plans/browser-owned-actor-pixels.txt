Private browser actor pixel ownership prototype
==============================================

Status: READY publication-budget follow-up, default OFF. No adoption or general performance claim. No server,
browser, HTTP listener or GPU launched by this worker. Based on main 8b888cd2f.

Goal
----
Avoid BrowserWorldSpriteCache's repeated source pixel hash, comparison and key
copy for actor sources whose exclusive ownership is mechanically enforced.
Keep every command's sampling, alpha, skew, mirror, order, dimensions and colour
transform in the cache key. Miss compositing, shaders and art are unchanged.

Ownership contract
------------------
* Existing Sprite constructors and setPixels still retain caller arrays and
  stay untrusted. They are never certified by array identity or a setter count.
* copyForOwnedActor is explicit NEW publication: one detached copy of a bounded
  source, not an in-place seal. The original object and its saved aliases still
  behave as before. Exact Sprite/Frame classes only; subclasses fall back.
* OwnedPixels holds private storage, a final nonescaping reader and an opaque
  version token. Sprite.setPixel changes the token after a successful write.
* Sprite.getPixels, OwnedPixels.expose, Frame.getPixels, and an auxiliary raw
  getter that aliases the primary plane permanently revoke that plane's trust.
  Saved raw references can then mutate at any later time: the ordinary full
  hash/compare path sees them. An escaped publication cannot be resealed.
* An owned Frame and its Sprite share one owner. Frame.changePixels and
  changeDimensions deliberately remain Frame-only changes; Sprite.setPixels
  deliberately leaves the Frame's old storage in place. Replacing one side
  does not silently reconnect the other. Legacy clone retains virtual getter
  behaviour; the owned private branch reads without escaping.
* Primary and auxiliary copy lengths each cap at 2,097,152 elements. Existing
  malformed, incomplete, divergent or unsupported sources remain legacy.
* Publication additionally caps NEW array payload at 64 MiB, unique copied
  frames at 8,192, and retained identity memo entries at 8,192. Exhaustion leaves
  the literal original frame/source in place. The memo also bounds unsupported
  and exhausted source references. Already-published frames preserve identity
  (including escaped ones) without consuming a new copy or memo entry.
* Accurate payload accounting includes the complete primary int[], a distinct
  transparent int[], and unknown byte[]. A transparent alias of primary is
  counted once and remains aliased in the copy. Repeated Frames share one copy.
  These limits bound incremental publication payload, not existing baseline
  assets or JVM object headers. The local memo temporarily retains originals
  and copies together: selected original+copied payload can reach 128 MiB at
  the 64 MiB copy cap, plus bounded frame/token/memo overhead and other assets.
  The memo and originals become collectible after publication returns unless
  another existing loader/reference owner retains them.
* Existing render-thread no-mutation-during-compose contract remains. Tokens
  are sampled from the ACTUAL command Sprite at compose time, never from an
  entry name, sprite ID or an earlier SpriteCommand construction.

Bounded production slice
------------------------
BrowserOwnedActorPixels.publish runs once at the end of mudclient.loadSprites,
after archive packs, external NPC/equipment sheets, material staff recolours
and equipment anchor changes. It handles Entry types PLAYER_PART, NPC and the
two equippable types. IdentityHashMap preserves repeated Frame references.
Generic SPRITE entries (including textures), authentic-mode sprites, dynamic
framebuffer/minimap captures and later arbitrary replacements remain legacy.
Textures' black-to-magenta post-load mutation is untouched.

GraphicsController's command null guards now use hasPixelData without exposing
the buffer. GPU-owned clipping still returns before software pixel reads;
software fallbacks can expose and revoke normally. Actor visible bounds and
the composite miss builder read owned planes without exposing them. Generic
UI/direct texture paths remain unchanged. No UI command stream rewrite.

Cache keys retain only the opaque token, not the source plane. Equal tokens
are sufficient only WITH exact metadata/transform equality. Different owner
tokens may reduce cross-Sprite equal-art deduplication; this is a hit-rate and
memory/performance trade-off to measure, not a correctness shortcut. Legacy
hash collision comparison, budgets, LRU, image IDs and epoch rules remain.

Private controls and evidence
-----------------------------
URL actorpixels=on/off, WebGL benchmark pages only; default OFF. Ordinary and
software URLs never inject the property. Java property:
spoiledmilk.browserOwnedActorPixels. Actual browser availability is also
required for production publication. Bridge getter:
BrowserWebGLBridge.isOwnedActorPixelsEnabled.

window.browserProof.ownedActorPixels reports requested/enabled plus lifetime
trustedLayers, legacyLayers, escapedLayers, subclassLayers, hashedPixels,
comparedPixels, copiedPixels, avoidedHashPixels, avoidedComparePixels, hits,
misses, cacheBytes and entries. Counters add once per layer/scan, not once per
pixel; export occurs only in the existing one-second observer.
Its publication subrecord reports payloadBudget/frameLimit/memoLimit,
copiedPrimaryBytes/copiedAuxiliaryBytes/copiedFrames, sharedReferences,
alreadyPublishedReferences, unsupportedFallbacks, byteBudgetFallbacks,
frameBudgetFallbacks, memoBudgetFallbacks, memoEntries and enabled. Fallback
reasons count unique memoized attempts, except unretained memo-cap rejections;
repeated memo hits are separately counted as sharedReferences.
