Private segmented TEXT raster (READY for preservation; rejected experiment)
=========================================================================

Actual same-artifact performance rejected this prototype: OFF 54.975261 FPS
versus ON 49.355973 FPS, a 10.2215% regression. Correctness, native execution,
fault recovery and UI checks passed; the implementation is NOT adopted.
Preserve/park this exact branch and all evidence without merging the feature.
Ordinary defaults and the public server were not changed.

Only consecutive final drawColoredString plot lists may defer. Parsing, random
colors, inline icons, font remapping and shadow/glyph order remain authoritative.
Own font snapshots at each TEXT, scalar plot/clip snapshots and once-only literal
replay; never reconstruct or rerun UI. Limits: 256 texts, 4,096 plots, 8 MiB snapshot
fonts, 2M clipped glyph work. Fresh MODE_WORLD C/T only and overlaydelta OFF.
A whole segment is materialized synchronously before every actual non-TEXT
C/T raster/read/escape/mode/clip/surface/frame barrier. Pure phase/policy changes
and proven GPU-descriptor-only wrappers may retain pending TEXT; no C/T read or
write occurs on those paths. Native status0 guarantees no writes and
may replay saved plots/fonts/clip once; after-write errors poison/hold the frame,
never replay over partial alpha. Recovery requires a fresh cleared world frame.

Closed maintained source contract (private prototype, no production adoption):
GraphicsController primitives, sprites/palettes/scales, minimap/rotations,
blur, framebuffer captures/reads, clear/fade, clip, frame/mode/owner/surface and
presentation methods all flush. Scene retains an alias and delegates to Shader,
MiscFunctions/static scanlines and depth-copy; their consuming render/resize/
bind paths flush first. ORSCApplet retains BufferedImage/DataBuffer aliases:
every presentation/getter and bind/read use flushes, not only initial binding.
mudclient editor line raw writes flush before access. FloatingHitSplat scratch/
measure/export always remains software and never defers. Public raw pixelData
is not privatized; unknown external plugins/reflection/concurrent aliases are
outside this closed private contract. A source-roster guard must reject new
unaudited maintained raw uses, including delegated alias consumers.

Ordinary OFF glyph/AA/coverage hot bodies must remain byte-for-byte source equal.
The capture guard is only at final TEXT plot dispatch. All other methods add
only opt-in barriers outside their per-pixel loops. Fonts are not identity-cache
safe: mutable source is snapshotted per TEXT; native input is a separate packed
copy so rejection replay uses untouched private Java snapshots. Native validates
all scalar/source/output extents, byte-range aliases, tokens and order before
writing. The registry/queue, suppression, poison boundary and native ABI were
implemented and tested as recorded below; actual performance rejected them.

Transactions and failure boundary
---------------------------------
The native ABI receives header 11 ints, 8 ints/TEXT, 5 ints/glyph, packed owned font
bytes and borrowed current C/T plus exact generation/sequence. Java snapshots
for rejection replay are separate from the native packet. Typed arrays are
normalized via intrinsic shape/buffer getters; shadow properties/proxies cannot
hide an output alias. Inputs may share a buffer only when byte ranges are
disjoint. No input views or buffers survive callback return. Scratch retains
only scalar resolved geometry and bounded counters; no GPU calls/await.

Status 0 is guaranteed zero-write and replays snapshots once. Replay detaches
pending records before callbacks, so an exception cannot retry a rendered
prefix. Any unknown/after-write callback failure poisons coverage, discards the
queue and throws a dedicated Error through ordinary legacy Exception/Runtime
wrappers. Only the outermost mudclient.draw catches it; current pooled 3D frame
storage is released, presentation is skipped and the prior good GPU image stays.
Scene building itself stages data; actual GPU submission begins in Bridge.
ORSC.draw and Bridge.present flush before retention/initialization/native calls.

Recovery does not merely reset metadata. A successful world begin genuinely
clears C/T; failed begin keeps poison. Poisoned opaque recovery explicitly
clears the complete RGB surface before reopening opaque ownership. A poisoned
next renderer frame clears its fresh C/T base before accepting new work. No
later reader may export partially native-written C, and no UI/game update rerun
or client-loop shutdown is used. Font payload is bounded to 8 MiB retained
snapshots and up to 16 MiB transient Java snapshot+flat copies, plus bounded scalar
arrays, owner C/T and engine/driver overhead outside that payload accounting.
