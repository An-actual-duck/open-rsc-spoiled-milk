Controls and preserved behavior
-------------------------------
New startup-only baselinereuse=on|off, default off. ON requires private benchmark
WebGL + wholezone=on + wholeram=on + staticscene=on. The Java path additionally
requires browser presentation, actual GLOBAL signed level0 native source,
requested plane0, no live terrain patches and bounded input. Unsupported startup
JAR APIs fail closed. No ordinary/native defaults, map, server, gameplay packets,
source admissions, readiness/input gates or Worker ACK rules change.

Capture candidate static models by exact (world x,z,id,direction); hashes only
index maps and never prove equality. Retire all old scenery/wall scene entries
with the existing stable removeModels compaction, removing all collision flags.
Rebuild the authoritative baseline in its original order. Matching static models
replace only clone construction. Every entry still runs original pick-bound
preparation, rekeying, lighting setup, current terrain-height sampling, translation
and collision materialization. Translation dirties the model so original normal,
light, projection and bounding-box reconstruction occurs. Walls are always fresh.
Animated game objects use the existing classifier and always clone afresh.

Proofs and bounds
-----------------
Exact owned primitive snapshots cover source clone inputs and configured target
raw geometry/material/picking metadata. Source transforms and transformed vertex
arrays are included because commitTransform can read them. Target raw geometry,
face indices, texture ranges (raw float bits), face parameters, pick indices,
vertex secondary light, fishing metadata and material/interaction flags are
checked; rotation/scales/shears must match the original placement. Derived target
normals/light/projection caches are deliberately not accepted as immutable proof:
the original factory/materialization path rebuilds them before presentation.

Snapshots are shared per object definition/template rather than per tree instance.
Source snapshots are validated once per template per baseline, and each candidate
instance has exact raw comparisons. Current definition/model reference, native
package identity, signed scope, custom-asset settings and lighting/geometry/fog
settings must agree. Scope/disconnect resets clear all proofs. A changed source,
definition or target refuses reuse. Duplicate placement identities never reuse;
duplicate physical model references refuse the entire optimized teardown, retaining
literal removal semantics. Pending/unloaded objects still take original terrain
availability checks. Source, actor and baseline authority remain upstream.

Admission:4096 objects,512 templates,16MiB conservative owned workspace bound.
Primitive snapshots are charged for full array extents, nested arrays, references
and conservative object overhead. Transient map/key/reference slack reserves512
bytes per object, with a4096-object reserve when creating proofs. Oversized inputs
or proofs use literal clone fallback. Only templates used by the completed current
baseline remain; candidate and verification maps are discarded after each replay.
This is a bounded baseline traversal, not a per-frame geometry rebuild or a claim
of bounded milliseconds on every device.
