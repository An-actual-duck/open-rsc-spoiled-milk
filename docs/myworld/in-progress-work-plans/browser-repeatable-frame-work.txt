Alignment candidate
-------------------
The literal frozen325 alignment function is the OFF control. Cached ON reuses
AWT target/bounds until logical size, DOM all-attribute/text/child mutations,
ResizeObserver, resize/scroll/fullscreen/display events, fonts/resource loads or
DPR invalidation. Active overlapping CSS motion uses actual bounded animation
identities and remains live-measured. Missing observation/animation APIs fall back
to live alignment. OFF disconnects observers/listeners; exact owned GPU CSS writes
and backing pixel dimensions do not invalidate logical layout. Stop is idempotent.
Private live window.browserBenchmarkAlignment(boolean) applies on the next align.
Stats expose requested/active/support, alignments/hits/reads/scans/invalidations.
Cover updates and ordinary AWT input remain on their existing paths.

This observes the current app/vendor DOM. Direct CSSOM insertRule or a new WAAPI
animation started without any DOM/motion event is not automatically detectable;
future app code using those paths must call invalidate or retain the live path.
It is not a general arbitrary-website layout cache. Actual current-app resize,
fullscreen, focus/input and pixel/bounds gates are required before adoption.
