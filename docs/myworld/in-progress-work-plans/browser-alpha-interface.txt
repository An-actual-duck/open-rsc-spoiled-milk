Browser alpha interface cleanup: private candidate
================================================

Status and scope
----------------
CPU/offline candidate ready for manager review and real Firefox acceptance.
No public server, endpoint, loopback policy, player map, renderer shader or ordinary
native window mode is changed. This is not a public browser deployment.

Player-facing changes
---------------------
Middle mouse moves from Graphics to General's Interface section. Stable action73,
the existing tilt/Classic behavior and client-settings persistence are retained.
The browser's Fit to tab and Fullscreen rows live in the in-game Graphics menu.
Native Windowed/Borderless/Fullscreen and software scaling retain their existing
controls; browser software compatibility adjusts scaling-row coordinates for its
two additional display rows. No session/lifecycle action is added to Graphics.

The permanent outer toolbar and engineering/login details are removed. A transient
Play/Cancel surface owns startup. It disappears for login/game; ordinary region
travel does not restore it. Fatal graphics/area-preparation failures expose a
transient Restart game/Close game surface. Closing the tab still disposes the
owned runtime. The retained hidden Stop element supports startup/recovery, not a
permanent gameplay bar. Normal in-game logout behavior is unchanged.

Only the outer document owns fullscreen. A Graphics request first calls the
outer requestFullscreen API before awaiting anything. If the browser rejects
that attempt or requires a fresh gesture, a transient Enter fullscreen/Keep
playing in tab dialog supplies that gesture. Escape/denial leave the game alive;
fullscreenchange updates the real observed setting and CSS fit. Dismissing/stopping
invalidates an outstanding request, including one whose promise resolves late.
No automatic fullscreen re-entry follows Escape. Native framebuffer dimensions
and existing CSS input-coordinate normalization are unchanged.

Initial loading uses plain Preparing game data / Preparing nearby area labels.
GPU/CPU/full-world retention language stays in diagnostics rather than gameplay
loading text. Readiness, source authority, coverage ACK and input gates remain
unchanged. Ordinary streaming keeps its transparent status and original gates;
this patch does not cover region stalls with an opaque loading screen.

The browser observer no longer overwrites zoom75/rotation128 every second merely
because benchmark optimizations are selected. Only an explicitly selected private
repeatable-v1 or renderer-combat-v1 fixture creates RepeatableCamera. Normal
exploration keeps the player's zoom and rotation. The existing explicit fixture's
one-time pin and drift reporting remain unchanged.
