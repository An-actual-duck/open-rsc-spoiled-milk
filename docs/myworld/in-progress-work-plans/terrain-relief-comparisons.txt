Terrain relief comparison prototype
===================================

Owner direction
Restore the familiar Classic terrain definition lost when Directional Remaster
terrain stopped using its fixed vertex-light relief. Try a small set of other
terrain cues for visual comparison. This is a private review candidate, not
approval of an AO/curvature art direction or a public deployment.

Four finite choices
-Dspoiledmilk.terrainDefinition=sun-only|classic-relief|relief-ao|relief-curvature
The default is classic-relief. Same-JVM review drivers may call the package
private RendererTerrainDefinitionSettings.setMode(Mode). There is no new
permanent menu. Existing Terrain Shading levels/setting persistence are retained.

SUN_ONLY preserves the accepted directional terrain/shadow path.
CLASSIC_RELIEF adds the existing Classic fixed vertex-light shape cue, normalized
against native flat legacy-light 72 (96 base plus flat diffuse -24). Its slope
weight preserves truly flat ground colors, and its factor is bounded 0.60..1.35.
It is intentionally not a pixel-identical rollback: corrected physical normals,
terrain light response and all near/far shadow fixes remain. Existing sun-relative
slope contrast remains unchanged; the current Terrain Shading control therefore
scales both that contrast and the added Classic layer in this initial prototype.
Owner review should determine whether to separate their controls afterward.

RELIEF_AO adds a cached render-only terrain-height shelter estimate. Eight local
rays sample 1..4 tiles above the local tangent. This helps sheltered depressions;
it is not screen-space AO, object contact AO, or a claim of full physical sky
integration. Maximum extra darkening is 22% at default strength 2, bounded 33% at
higher strength. Unknown samples contribute no occlusion and incomplete neighbor
coverage fades toward neutral.

RELIEF_CURVATURE instead uses signed local height bending, darkening concavities
and gently emphasizing ridges. Default extra modulation is bounded +/-12%, with
a maximum +/-18%. This is an artistic height cue, not another cast shadow.

Both extra fields occupy RG channels of one small world-aligned texture, using
sampler 7 only when supported. Alpha represents known coverage. Field extent is
bounded 512x512 (1 MiB RGBA); it is generated from immutable received terrain
geometry on the matching renderer plane/context. Halo vertices use the primary
presentation-world anchor, never a second per-halo origin translation.
SUN_ONLY and CLASSIC_RELIEF do not build this field at all. Lighting, camera and
animated texture pixels are not field inputs. GPU content is retained until a
field revision and deleted on renderer/session cleanup. Caller sampler 7 binding
and active texture unit are restored. No new VBO, asset, map, protocol, loader,
network authority or player data contract is introduced.

The terrain definition factor applies before additive emission. Object relief,
Classic/non-directional lighting and the accepted geometry shadow implementation
are unchanged. This prototype does not attempt the separate minor fence ripple.

Completed checks so far
- Client build and existing complete renderer guardrails pass.
- Existing hardware geometry shadow/terrain physical light suite passes without
  changing accepted normals, contact/alpha/roof/far transition tests.
- Pure field probes keep flat/planar surfaces neutral, darken a sheltered bowl,
  distinguish signed ridges, treat unknown coverage neutrally, cache actual
  immutable frames, reject another plane, survive epoch/session transitions,
  and retain identical world-aligned pixels across presentation rebasing.
  Material-only changes and rebasing do not rebuild the field. The bounded
  256-entry immutable-storage memo only scans new geometry once; its pure height
  result, placement, active plane and context epoch determine field validity.
- A stitched native-style halo/chunk surface gives byte-identical fields to an
  equivalent single surface; no per-chunk curvature/occlusion boundary is added.
- Production GLSL probes keep flat 128 at all tested strengths and all four modes.
  At default strength 2, fixed relief probe lit/dark 136/80 versus SUN_ONLY 128/128.
  Zero strength and non-terrain objects are neutral to this new layer.
- Controlled AO/curvature/unknown-alpha probes are bounded as stated.
- The actual full shader retains emission 64 across all three restored modes,
  both extreme legacy-light values and high strength.
- Actual TerrainDefinitionTexture/real shader binds its own sampler 7, restores
  caller texture/active unit, leaves them unchanged in SUN_ONLY, deletes its own
  texture idempotently and preserves the caller texture. GL error remains 0.
