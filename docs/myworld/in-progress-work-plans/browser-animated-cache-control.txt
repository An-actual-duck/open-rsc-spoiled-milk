Important native API detail
WorldChunkBufferKey.from(chunk,false) does NOT select old per-pose identity for
animated chunks: both boolean variants use positional animated keys. OFF must
explicitly construct the immutable-storage key with drawOffsetStorage=true and
the current storage signature. Tests protect this distinction.
