Browser primitive chunk coverage experiment
==========================================

Status: CPU-validated private default-OFF experiment; READY for manager review.
Actual browser timing/VFX/transition measurements remain pending.
Base/frozen source 2067399022fe0fb2f336437f30b1621ffa99a80c.

Scope: NativeLayeredTerrainChunk.covers currently reconstructs two long products
and upper-bound additions for every call. Precompute int minimum/exclusive-maximum
bounds once in immutable constructor storage, only AFTER all original validation,
copy and error paths. Eligible calls use four int comparisons; an exclusive upper
bound of Integer.MAX_VALUE+1 remains on the literal old long path. No floorDiv,
indexing, tile decode, height lookup, chunk scan, World/Snapshot state or cache is
changed. The old constructor validation/copy prefix, covers fallback, tileOffset,
createTile, primitive readers and coordinate validator have literal source guards.

Property spoiledmilk.browserPrimitiveChunkCoverage defaults false. Actual static
NativeLayeredTerrainChunk.isBrowserPrimitiveChunkCoverageEnabled() also requires
the real optional browser presentation capability. Ordinary desktop/native and
OFF calls use the unchanged long block. Bounds storage adds four ints and one
boolean per existing immutable chunk; no map-wide cache/array/list is introduced.
No Java long arithmetic is introduced on the eligible covers hot path.

Private benchmark query chunkcoverage=on|off is the sixth independent experiment.
It is accepted only by WebGL+benchmark URLs, defaults OFF, rejects malformed input,
and has a generic actual optional getter receipt. Ordinary/software URLs forward
no policy. An older JAR lacking the getter reports unavailable OFF and rejects
requested ON; availability is not inferred from a requested property.

Frozen parity fixture provenance: Snapshot/real World height corpus is explicitly
reused as TEST INPUT from 9fd3957429d43ca07e929a999461f1b540f752cf. None of that
parked branch's height/index implementation is imported. This branch's World and
Snapshot files must remain byte-identical to frozen 206. New direct Chunk corpus
covers all ten accepted divisor sizes, all twelve terrain encoding names, explicit
voids, negative/near-zero/extreme accepted coordinates, exclusive upper overflow,
inside/outside boundaries, immutable source bytes, tile/height/overlay readers and
constructor failure classes/messages/order. Real World corpus retains mutable
loaded-sector precedence, malformed scope/mapping, offsets and signed sentinels.
Test-only source instrumentation distinguishes literal long products from actual
int branch executions. No production counters are added.

Remaining limits
----------------
The counters establish fewer long operations in eligible covers calls, not lower
frame time. The extra branch/browser capability read, immutable per-chunk metadata
and constructor precomputation have costs. Core load, terrain scan counts, tile
indexing and all other render preparation remain unchanged. Matched actual
browser idle/combat/VFX and region transition timing must decide adoption. Keep
the property default OFF until that decision; no FPS or stutter claim is made.
