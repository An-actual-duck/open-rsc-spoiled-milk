Independent transport writer-span review
========================================

Scope and exact source
----------------------
Reviewed ai1 implementation e87fb8e501fd2154ac66286c10823c4227bb3921 against
frozen baseline c7ed5960abf0bc6a514852b998151b7a5856a6fc. This ai2 branch
contains independent CPU fixtures, their source-bound runner and this report;
no production source edits. No browser, GPU or server process was started.

The private switch spoiledmilk.browserOverlayWriterSpans=true requires both
delta transport and rectangle mode on/packed. Only plotLetter,
plotLetterAntialiased and drawBoxAlpha open scopes. Each scope validates the
bounded destination rows, then premarks each entered row in transport metadata.
The original covered-pixel opaque/multiply operations still update literal T
and written/coefficient state. Only redundant transport.mark calls are skipped.

The source/destination contract is deliberately asymmetric. Destination row
geometry is validated with long arithmetic before admission. Glyph source
bytes/strides are NOT prevalidated: a null, short or malformed source can fail
after a bounded destination row was premarked. The conservative unexecuted row
suffix is permitted transport overmark. Original exception/catch behavior and
literal C/T prefixes must remain exact. Premarking glyph bounds via opaqueSpan
would be incorrect because transparent source holes must not change T.

Source review and boundaries
-----------------------------
Scope admission checks the actual coverage owner and active transport with no
pending plan. Pending admission invalidates transport before a zero-source
glyph could avoid all per-pixel calls. Row premarks precede the original row
loops; unexpected owner/index/span/nesting and borrow/prepare/reset disable
suppression and invalidate partial history. Both glyph methods retain their
distinct historical catches; all three target methods close scope in finally.
The scope stores numeric row bounds only and does not retain new source arrays.
Counters saturate in five bounded int slots; diagnostics are carried on the
existing transport call, not a separate per-frame JNI call.

No source-backed correctness blocker remains for this reviewed checkpoint.
Conservative overmark can enlarge the ACK footprint and subsequent upload,
including for all-zero glyphs and failed source rows. Branches and counters
also have cost. CPU parity therefore does not imply an FPS improvement, and
this report does not recommend enabling the switch by default. Actual world
writer occupancy, source-bound hardware output parity and matched full-game
timing remain separate manager gates. The model assumes the existing render-
thread ownership; it does not establish safety for concurrent drawing.

Workspace-layout check reports the inherited legacy assets/sprites entry and
unclassified legacy output-root items. New outputs use the declared tests
category; no inherited data was removed.
