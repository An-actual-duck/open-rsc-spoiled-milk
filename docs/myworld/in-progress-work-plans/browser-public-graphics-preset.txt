Public browser alpha graphics compatibility — November 12, 2026

The whole-zone catalogue deliberately rejects incompatible vertex packing.
Its accepted packing tuple is [0, 0, 1, 0]: unbaked brightness, Fog On,
Directional lighting and Smooth geometry. Advertising selectable Fog/Lighting/
Geometry while using that fixed catalogue could turn a menu choice into a fatal
catalogue mismatch. Saved local renderer modes could cause the same problem.

This change gives only the explicitly selected public browser alpha effective
ON/DIRECTIONAL/SMOOTH modes. The ordinary settings loaders still parse and retain
the stored preferences separately. Public cycles/setters do not modify that
stored mode, and public save writers omit these three settings entirely,
preserving their original keys/values and legacy fog alias. A future ordinary
or private session can therefore read the original choices. No account settings,
roof option, brightness, shaders, catalogue/hash guards, native renderer or
private startup policy are overridden or weakened.

Graphics groups the three unavailable choices under 'Browser preset (fixed)',
then groups supported controls under 'Adjustments'. Fixed rows have no action;
stale direct IDs 60/61/62 are also refused. Brightness/dimness remains live in
actual shader uniforms while directional unbaked packing retains its zero word.
The setting marker is the existing exact public bootstrap flag; no import from
the other worker's unmerged public bootstrap is required.

Changed production files: BrowserPublicGraphicsPreset.java, RendererFogSettings,
RendererLightingSettings, RendererGeometrySettings and RendererSettingsPanel.
Existing loader/persistence behavior with the public flag absent remains intact.
The effective getter path is shared by the real menu, real backend packer and
shader uniform exporter, so the menu cannot report a different mode from packing.
