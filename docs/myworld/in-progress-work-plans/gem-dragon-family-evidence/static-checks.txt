- server tick = 640ms
- poison ticks every 8 server ticks (5.12s)
- successful hit opportunity every 3 ticks (1.92s)
- every attack is treated as a successful hit to isolate poison throughput

- armor poison starts at 50% and steps down to a 10% floor

- poison drains 3 power per poison tick
- if weapon and armor both proc on one attack, only the stronger applied value is used
