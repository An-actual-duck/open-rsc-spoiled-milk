Policy
------
The outer page has explicit Start/Stop controls. Java runs in a disposable
same-origin sandboxed iframe so an explicit Stop can remove its listeners and
VM context. This is lifecycle containment, not a security boundary against its
own same-origin scripts. No keyboard-lock API is used, system clipboard access
is not requested, input methods are disabled for this private diagnostic page,
and browser shortcuts are not overridden by the wrapper.

Only explicit Stop, page exit, or Java completion/bootstrap failure ends the
session. Escape remains normal game/AWT input; blur and tab hide/restore merely
record advisory state. The manager explicitly chose these ordinary gameplay
semantics: changing tabs or closing a menu must not destroy a logged-in client.
Existing Java/AWT focus handling remains authoritative for game keys; no second
held-key implementation or desktop/global input hook was introduced.

Explicit disposal closes the application-owned transport and optional GPU
backend before removing the iframe. It is idempotent and also used on page exit.
A new Start creates a fresh VM; messages from removed or unrelated contexts are
ignored through exact frame-window and origin checks. The original Java client,
public server, owner accounts, and hosted database were not changed.

Optional WebGL frontend seam
---------------------------
Only mode=webgl imports the separate renderer worker's webgl.js. Its
createBrowserWebGL(canvas,report) object supplies natives, stats, canvas and
dispose. Those natives are merged before cheerpjInit. A pointer-transparent
canvas is aligned to the game framebuffer inside CheerpJ's AWT window canvas,
excluding its20px titlebar. Software/native/mesh modes keep their normal path.
Java-loop FPS and GPU counters remain separate; selecting this mode is not a
claim that GPU rendering succeeded or matches the desktop renderer.

The implementation of webgl.js and the production bridge belong to the separate
feat/browser-webgl-renderer handoff. This branch does not contain that module
and does not advertise a WebGL link until that dependency is integrated. The
manager will integrate both reviewed branches before exposing the GPU mode.
The renderer worker borrowed exact frontend checkpoint
3da4603d183f8b6720ee78e4cdc2ce776641909c into a new ignored immutable test stage;
its stage records copied file hashes. Such borrowing is test composition, not
an implicit merge or a claim that either branch alone includes the full GPU mode.
