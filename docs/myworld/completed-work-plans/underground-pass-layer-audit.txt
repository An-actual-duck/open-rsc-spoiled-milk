Confirmed fixes
---------------
1. The crumbled rock is 728 at (672,588,-1). It previously called
   teleport(713,581), whose compatibility overload keeps the current native
   level when terrain exists there. It therefore stayed underground. The
   callback now explicitly targets (713,581,0). The complete real map confirms
   that landing has traversal mask 0 and four legal adjacent walking exits.
   Stage-zero entrance refusal remains, both before Biohazard completion and
   before starting Underground Pass. Stages 2 and completed (-1) still enter
   at (673,588,-1), and the exit works for both.

2. The puzzle levers manufactured detached cage objects using packed Y 3449
   and registered them directly. The real callback reproduced the same
   'Entity legacy Point differs from its WorldLocation' error as the bridge.
   They now use the existing native lookup/replacement/restoration APIs.

3. Using a plank on northern passage 825/829 previously consumed the plank,
   then threw at direct registration of its packed-Y temporary visual. The
   temporary planks now get an explicit native location and package-owned
   identity through existing APIs, with the original five-game-tick removal.
   Repeated crossings reuse the active visual, and unrelated scenery is not
   overwritten. Both directions, visibility, floor isolation and removal pass.

4. Recovered Koftik's stage-eight escort had the same implicit-current-level
   destination defect as the crumbled rock. Its original surface entrance
   landing (714,581,0) is now explicit; the quest stage remains eight.

5. The north/south stone steps and the catwalk fall table used legacy plane-
   zero hard destinations. The compatibility overload instead retained the
   catwalk's native -1 level. Twenty-one hardcoded destination calls now name
   level zero explicitly. These are original lower cave-floor locations, not
   newly selected positions. Actual callbacks cover both stairs, twenty
   obstacle fall routes, the original fall damage, and forced quest-stage
   4-to-5 progression. Success rolls and relative catwalk crossings are unchanged.

The Iban tomb candidate was checked and left unchanged: the actual tomb is
at (724,654,0), and its existing temporary claws correctly appear on that
floor, deal the original 24 damage at 99 HP, and disappear afterward. It does
not need a rewrite merely to use native ownership instead of the working
surface compatibility path.

Coverage limits
---------------
This is not a complete quest walkthrough. The lever inventory is complete for
the stated installed-map region and all Underground Pass lever handlers were
checked. Other dialogue branches, menus, every obstacle's success path, and a
legacy-runtime quest playthrough are not claimed. In particular, the broader
source scan noted old packed-Y special-case conditions in Map1 clear-rock and
Map2 rope-grill handlers; those branches need focused intent/reproduction work
before deciding whether to change their side restrictions. They are outside
the verified lever/exit/route changes above.

Quality gates: client/server/world-builder compilation passes the maintained
warning gate (no new gated warnings). Changed-source static analysis passes:
no PMD/Ruff findings and no new SpotBugs findings. Existing Checkstyle findings
are reported outside newly changed lines. The server artifact audit and diff
whitespace check pass. Workspace-layout checking reports pre-existing ignored
output-root directories retained in this recycled worker; this task adds its
outputs only beneath the declared output/tests category and preserves those
older directories.

Public activation requires a separately authorized server maintenance window.
No public process was stopped or restarted by this worker.
