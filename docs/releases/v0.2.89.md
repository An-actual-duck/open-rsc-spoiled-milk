# Spoiled Milk v0.2.89

This update brings the public game onto the reviewed map-loader foundation used
by the private RSC Development Toolkit. Update your game client before playing.

- Consolidated map-source selection and terrain/collision lookups, preserving
  signed levels, wide elevations and the existing world.
- Stronger whole-map validation before placements are registered.
- Client recovery fixes for missing terrain-cache references during travel.
- Fixed ground items disappearing after player death until leaving the area.
- Hosted launches and release packaging respect the reviewed installed server
  and client map pair rather than pinning an older external snapshot.

The release is based on v0.2.88, with only the reviewed loader and deployment
changes added. Existing game definitions, artwork, maps and player data are
preserved. Unfinished Slayer Tower additions are not included.

Map editing remains copy-first. Build in an authoring copy, Save, then import
offline with a verified backup. Public map updates still require a reviewed,
clean, published release; do not edit the detached live checkout directly.

The Development Toolkit remains a separate private pre-alpha, not a public
toolkit release. No automatic server-runtime upgrader is included.
