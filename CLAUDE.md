# Spoiled Milk

Read [AGENTS.md](AGENTS.md) and identify your workspace role before making
changes. Follow the preflight for that role.

If you are working with an external contributor in their own clone, read
the [Claude onboarding guide](docs/contributor-guides/claude-onboarding.md).
Use the contributor helper for task branches, checkpoints, and exact-commit
handoffs. The maintainer manager reviews, integrates, and publishes changes.

Use one coding session in the contributor's clone. Read the assigned issue
or plan before editing and ask the contributor to review the full diff
before handoff.
