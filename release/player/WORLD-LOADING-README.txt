SPOILED MILK - @VERSION@
=======================

Extract the entire ZIP. Keep game-files beside the launchers.

Choose World Chunks for traditional loading or World Streaming for smoother
travel on a server that supports it. Both launchers open the same login screen
and use the same client files and settings.

WINDOWS (64-bit)
  Play Spoiled Milk - World Chunks.cmd
  Play Spoiled Milk - World Streaming.cmd
  Java is included.

LINUX
  play-spoiled-milk-world-chunks.sh
  play-spoiled-milk-world-streaming.sh
  Install Java 17 or newer. If your file manager opens a script as text,
  run it with sh from a terminal.

macOS (Intel or Apple silicon)
  Play Spoiled Milk - World Chunks.command
  Play Spoiled Milk - World Streaming.command
  Install Java 17 or newer for your Mac's processor.

The original launch filenames open World Chunks.
