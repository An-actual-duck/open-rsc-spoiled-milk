SPOILED MILK - @VERSION@
=======================

Extract the entire ZIP before playing. Keep game-files beside the launch files.

WINDOWS (64-bit)
  Open Play Spoiled Milk.cmd.
  Java is included; you do not need to install it separately.

LINUX
  Run play-spoiled-milk.sh.
  If your file manager opens it as text, open a terminal in this folder and run:
    sh ./play-spoiled-milk.sh
  Requires Java 17 or newer.

macOS (Intel or Apple silicon)
  Open Play Spoiled Milk.command.
  Requires Java 17 or newer for your Mac's processor.

All launchers automatically check for updates before starting the game.
