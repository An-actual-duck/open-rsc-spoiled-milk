# Blight — approved Thorn artwork

The owner selected concept A, Thorn, on October29,2026. This is its native-size
translation, visually approved by the owner on October29,2026 ("that'll work"). No gameplay IDs, definitions, recipes,
infusion cost or production icon were installed.

The owner-authored existing `resources/sigils/stone.png` substrate stays exact
outside44 glyph pixels, including alpha. Both new forms are28×25, with a48×32
inventory reference canvas offset13,4 matching the native blank-rune anchor.
A short crooked stem grows into two downward thorn hooks; there is no skull,
droplet, god star, pinecone or upward Zamorak horn fork. Carved uses existing
uninfused sigils'160 grey; infused uses one dark purple96,24,100. No glow or
extra shading was introduced into the family's single-colour symbol language.

`author.lua` draws the symbol in Aseprite on a separate editable layer above the
untouched owner substrate. Both `.aseprite` documents round-trip pixel-exactly.
`review/index.html` compares at1× and6× nearest against existing Grace/Zamorak.
The28×25 source shape and48×32 full canvases are both available; they are not
resampled or autofitted. The large four-concept brainstorm sheet is external
review provenance, not a production sprite source and not packed into the game.
