# materials/gems-and-crystals

AI visual references only. Read [the library rules](../../README.md) first.

Cut and uncut forms use different highlight geometry. Separate loose gems from pearls-in-shell and magical glow examples; borrow only the intended material treatment. Pink shards have inconsistent export bounds and are not a default canvas-size reference.

## Contact sheets

- [contact-01.png](contact-01.png)

The sheets are 3x nearest-neighbour previews on a checkerboard. Individual PNGs below are native-size RGBA canvases. The checkerboard, borders and labels are NOT sprite art.
