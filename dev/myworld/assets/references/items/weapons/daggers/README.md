# weapons/daggers

AI visual references only. Read [the library rules](../../README.md) first.

Start with items:80 for the ordinary RSC dagger silhouette and scale. Items:385 uses the same small-blade vocabulary with green poison coloring. Those two have handles toward lower left and tips toward upper right. Dark/glowing daggers 420/421 are larger, ornate exceptions with the opposite diagonal; do not inherit their size or angle unintentionally. Keep the short blade and small guard legible. The ordinary base is also reused for throwing knives.
